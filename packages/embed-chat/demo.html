Chat widget demo

This page loads the built widget bundle from /embed/widget.js and opens the chat in canned demo mode. No credentials are needed; every response is sample content so the full response-card design can be reviewed offline.

Try it

Use the chat launcher at the edge of this page. The preview shows structured response cards: cited evidence, follow-up suggestions, progress, and proposals.

Connect a live organization

Append query parameters to switch from demo mode:

  • Live mode: ?mode=live&handle=your-org&apiKey=crk_…
  • API base override: &apiBase=https://…

Local workflow: serve this page and /embed/widget.js with npm run demo in packages/embed-chat, or copy the bundle to a frontend's public/embed/ and open the page through that dev server.
